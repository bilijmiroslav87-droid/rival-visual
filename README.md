# Collapse Client

Клиент для Minecraft Java 1.21.11 (Fabric), заточен под SpookyTime / FunTime-подобные сервера. Работает в Fold Craft Launcher.

## Сборка
GitHub Actions собирает jar при каждом пуше (Actions -> последний прогон -> Artifacts -> collapse-client).

## Управление
- RShift: меню. ЛКМ вкл/выкл, ПКМ настройки, СКМ назначить клавишу
- C (зажать): Zoom
- Конфиг: config/collapse-client.properties

## Модули (53)
Combat, Movement, Visuals, Player, Misc. Подробности в меню.
