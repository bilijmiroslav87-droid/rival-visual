# Collapse Client

Клиент для Minecraft Java 1.21.11 (Fabric). Работает в Fold Craft Launcher.

## Сборка
GitHub Actions собирает jar при каждом пуше (Actions -> последний прогон -> Artifacts -> collapse-client).

## Меню (v0.11.0), стиль Glass Menu
Дизайн взят из рабочего мода Glass Menu (твой репозиторий jdjdjd/glassmenu.zip): матовое стекло, слева сайдбар с вкладками
Visuals / Cosmetics / HUD / Player / Movement / Combat / Misc, справа сетка карточек в 2 колонки (название, On/Off, тумблер).
Шрифты Poppins и Frick подключены через ванильный TTF-провайдер (font/ui*.json), как в Glass Menu.
- RShift: открыть/закрыть. ЛКМ по карточке: вкл/выкл. ПКМ: окно настроек. СКМ: бинд. Ctrl+F: поиск.
- Слева внизу: Profiles и Theme. Справа под окном `font ok` или `FALLBACK`.

**Aura** (вкладка Cosmetics): шляпа, крылья, нимб, орбиты, след и всплеск при прыжке на частицах, как в Glass Menu.
Работает в 1-м и 3-м лице и не зависит от 3D-слоя рендера.

## HUD
Как в хабе: два ряда пилюль (бренд | ник, fps, время; координаты | пинг | скорость), список модулей справа капсом с акцентной полоской.

**CustomFog** теперь настоящий туман мира (цвет, начало и конец в блоках, радуга), а не рамка по краям экрана.

Стеклянные плашки с бликом и градиентной линией: водяной знак с переливающимся названием, список модулей со свечением,
уведомления с таймером, TargetHUD (показывает игрока, на которого смотришь, без зависимости от других модулей), Keystrokes с нажатием.

**Модуль HUD (всё в одном)**: одна панель с координатами, FPS, пингом, скоростью, временем, сессией и эффектами.
Каждая строка включается отдельно в настройках модуля, позиция: слева снизу / слева сверху / справа снизу.

## Косметика (v0.9.0)
Вкладка «Косметика»:
- **Крылья**: Ангел, Демон, Бабочка, Дракон, Феникс, Кристалл, Призрак, Кибер.
- **Головные уборы**: Корона, Нимб (вращается), Рога, Шляпа мага, Кошачьи уши, Антенны, Венок, Самурай.
- **Хвост** (виляет), **Орбиты** (три светящихся спутника), **Плащ**.
- Цвета: Тема, **Градиент**, Радуга, Золото и др. Свечение, размер, скорость взмаха, парение.
Видна на твоём персонаже (F5, инвентарь).
