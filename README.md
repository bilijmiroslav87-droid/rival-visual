# Collapse Client

Клиент для Minecraft Java 1.21.11 (Fabric). Работает в Fold Craft Launcher.

## Сборка
- GitHub Actions собирает jar автоматически при каждом пуше (Artifacts -> collapse-client).
- Локально: `./gradlew build`, готовый jar в `build/libs/`.

## Функции
- Меню: RShift
- GlowESP - подсветка сквозь стены
- Fullbright - максимальная яркость
- Zoom - зажми C
- AutoSprint - автоматический спринт
- HUD: водянка Collapse Client + список активных модулей
