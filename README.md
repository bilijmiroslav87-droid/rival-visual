# Collapse Client

Клиент для Minecraft Java 1.21.11 (Fabric). Работает в Fold Craft Launcher.

## Сборка
GitHub Actions собирает jar при каждом пуше (Actions -> последний прогон -> Artifacts -> collapse-client).

## Меню (v0.7.0)
- RShift: открыть/закрыть меню. Окно можно таскать за шапку.
- Слева навигация по категориям, **Избранное**, **Профили**, **Настройки**.
- ЛКМ по карточке: вкл/выкл. ПКМ: панель настроек справа. СКМ или чип внизу: назначить клавишу.
- Звёздочка на карточке: в избранное. Ctrl+F: поиск.
- **Профили**: сохранение и загрузка нескольких конфигов (config/collapse-client/profiles).
- **Настройки клиента**: масштаб меню, скорость анимаций, затемнение, 8 тем, позиция списка модулей и т.д.
- Шрифты: Manrope (текст) и Unbounded (заголовки), с кириллицей. Скругления антиалиасные.
- C (зажать): Zoom.
- Конфиг: config/collapse-client.properties

## Косметика (v0.7.0)
Вкладка «Косметика» в меню: 3D-крылья (ангел, демон, бабочка, дракон), головные уборы (корона, нимб, рога, шляпа мага), плащ.
Цвет, свечение, размер и скорость взмаха настраиваются. Видна на твоём персонаже (F5, инвентарь).
